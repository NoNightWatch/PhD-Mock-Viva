# Asset provenance

- `../shared/study-hall.png`: original AI-assisted artwork generated for this repository using the built-in image-generation tool. It depicts a fictional study hall with original characters. No existing game asset was supplied or copied.
- `../zh/*.svg` and `../en/*.svg`: original pixel panel artwork generated by `build-panels.mjs`. Each language has matching title, section, and feature panels. The shared hero has no language-specific text.
- The Latin pixel wordmark uses a small original rectangle-based glyph set defined in the script. Other labels use system font fallbacks. No font binary or third-party icon library is distributed.
- The style brief uses retro pixel RPG motifs, navy, gold, and mint. This does not imply affiliation with any game or publisher.

## Rebuild the panels

For maintainers only, run from the repository root with Node.js 18 or later:

```sh
node assets/source/build-panels.mjs
```

This regenerates the SVG files in `assets/zh/` and `assets/en/`. Node.js is not required to use the skill. The hero remains unchanged. To revise the hero, use the generation brief below and inspect the new output before replacing it.
