# Rebuild the page panels

For maintainers, run from the repository root with Node.js 18 or later:

```sh
node assets/source/build-panels.mjs
```

This rebuilds the 26 Chinese and English SVG panels. Node.js is needed only for rebuilding these page assets. Reading the viva guide and practising with an assistant require no local runtime scripts.

Keep each language's labels, download buttons, and README descriptions consistent. Check text width, contrast, and narrow layouts after changing a panel. The two cover PNGs are maintained separately.
